= What is technical writing?


To become a technical writer 
we first need to define what is the purpose of technical writing.

== It's purpose
* Help readers achieve their goal whether it is to do or learn something.
* To be easily readable and accesible. Minimalism is key.
* To be accurate and clear about what actions to take to achieve the desired outcome.
 

== Ideal outcomes of correct implementation 

* Customer is able to understand the product's purpose and utilization without having to contact the developers.
* Sharing of information is swift and easy.
* Developers can troubleshoot code much faster.


= Essential skills

A technical writer combines communication with technical knowledge to create documentation.

== Writing skills
Writing skills form the foundation of technical communication.

=== Key writing skills 
* using precise language
* organizing information in a logical structure
* consistent terminology throughout the document
* adapting to the target audience
* following style guides and standards
* minimalism is key

== Technical skills

Technical knowledge enables accurate communication and effective collaboration with SMEs.

=== Important technical skills

* Operating system fundamentals
* Networking
* Software development principles
* Command-line usage
* Version control systems (Git)
* Documentation markup languages (AsciiDoc, Markdown)

== Research and Analytical Skills
Accurate documentation depends on reliable information. Research skills help technical writers gather information from multiple sources

=== Research activities

* Reviewing technical specifications
* Consulting SMEs
* Comparing information from multiple sources

== Communication and Collaboration Skills

Documentation projects often involve cooperation with others. Effective communication improves the quality and consistency of documentation.

=== Communication skills

* Conducting interviews with SMEs
* Gathering and incorporating feedback
* Participating in content reviews

= How to write correctly

== Minimalism
* Don´t overcomplicate your texts. Minimalism means using as few words as you can to transfer information.
* Be careful about shortening your text too much, it still needs to convey the information correctly.
* Tip for you - Avoid using adjectives where they are not important.

== Language

* Use the simplest words in your vocabulary.
* Prioritize using active voice over passive voice, it gives more clarity to your text.

== Style guides

Microsoft writing style guide is considered the best for beginners.

* *IBM Style* – Comprehensive and professional, but less beginner-friendly. link:https://learn.microsoft.com/en-us/style-guide/[link]
* *SUSE Documentation Style Guide* – Fairly welcoming to new writers. link:https://developers.google.com/style/[link]
* *Apple Style Guide* – Easy to read and well organized, but primarily aimed at Apple platforms. link:https://www.ibm.com/docs/en/ibm-style/[link]
* *Microsoft Writing Style Guide* – One of the most beginner-friendly guides, emphasizing clear, conversational language. This document is written in it for example. link:https://developer.apple.com/design/human-interface-guidelines/[link] 
* *Google Developer Documentation Style Guide* – Very approachable for new technical writers, modern writing principles. link:https://documentation.suse.com/[link]
